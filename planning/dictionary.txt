3. orig_ma
--------------------------------------------------------------------------------
MEANING: Metro area code of shipment origin (combines with orig_state to form
         orig_cfs_area). 99999 = Remainder of state (no metro breakout).
         00000 = metro area suppressed. See orig_cfs_area below for full names.
VALUES:  See CFS AREA CODES section at the bottom of this file.

--------------------------------------------------------------------------------
4. orig_cfs_area
--------------------------------------------------------------------------------
MEANING: CFS Area of shipment origin. Format: "STATE-MA" (concatenation of
         orig_state and orig_ma, e.g. "24-12580" = Baltimore, MD).
VALUES:  See CFS AREA CODES section at the bottom of this file (132 valid areas).

--------------------------------------------------------------------------------
5. dest_state
--------------------------------------------------------------------------------
MEANING: FIPS state code of the shipment's destination (US only; CFS excludes
         imports and shipments to/from US territories).
VALUES:  Same code list as orig_state above.

--------------------------------------------------------------------------------
6. dest_ma
--------------------------------------------------------------------------------
MEANING: Metro area code of shipment destination (combines with dest_state to
         form dest_cfs_area).
VALUES:  See CFS AREA CODES section at the bottom of this file.

7. dest_cfs_area
--------------------------------------------------------------------------------

VALUES:  See CFS AREA CODES section at the bottom of this file.

--------------------------------------------------------------------------------
12. shipmt_value
--------------------------------------------------------------------------------
MEANING: Value of the shipment, in dollars. Raw/unweighted per-shipment value
         (rounded to nearest integer; noise-infused and top-coded for
         confidentiality). Multiply by wgt_factor before summing to estimate
         population totals.
VALUES:  0 - 9,999,999,999 (numeric)

--------------------------------------------------------------------------------
13. shipmt_wght
--------------------------------------------------------------------------------
MEANING: Weight of the shipment, in pounds. Divide by 2000 to convert to tons.
         Multiply by wgt_factor before summing to estimate population totals.
VALUES:  0 - 9,999,999,999 (numeric)

--------------------------------------------------------------------------------
14. shipmt_dist_gc
--------------------------------------------------------------------------------
MEANING: Great circle (straight-line) distance between shipment origin and
         destination, in miles.
VALUES:  0 - 99,999 (numeric)

--------------------------------------------------------------------------------
15. shipmt_dist_routed
--------------------------------------------------------------------------------
MEANING: Routed (actual road/rail/etc. path) distance between shipment origin
         and destination, in miles. Used (with wgt_factor and shipmt_wght) to
         estimate ton-miles.
VALUES:  0 - 99,999 (numeric)

--------------------------------------------------------------------------------
16. temp_cntl_yn
--------------------------------------------------------------------------------
MEANING: Whether the shipment used temperature control during transport.
VALUES:  Y = Yes      N = No

--------------------------------------------------------------------------------
17. export_yn
--------------------------------------------------------------------------------
MEANING: Whether the shipment was an export.
VALUES:  Y = Yes      N = No

--------------------------------------------------------------------------------
18. export_cntry
--------------------------------------------------------------------------------
MEANING: Final export destination region (only meaningful if export_yn = Y).
VALUES:
C = Canada
M = Mexico
E = Europe & Africa
A = Asia & Oceania
S = Rest of the Americas
N = Not an export

--------------------------------------------------------------------------------
19. hazmat
--------------------------------------------------------------------------------
MEANING: Hazardous material (HAZMAT) classification of the shipment.
VALUES:
P = Class 3.0 Hazmat (flammable liquids)
H = Other Hazmat
N = Not Hazmat

--------------------------------------------------------------------------------
20. wgt_factor
--------------------------------------------------------------------------------
MEANING: Shipment tabulation weighting factor. Used to expand this one PUF
         shipment record up to the total population of similar in-scope U.S.
         shipments it represents in 2017. Also interpretable as an estimate of
         the total number of shipments of this type. IMPORTANT: to estimate
         totals (value, tonnage, ton-miles), multiply shipmt_value / shipmt_wght
         by wgt_factor BEFORE summing across shipments - do not sum the raw
         columns alone.
VALUES:  0 - 786,400.0 (numeric, rounded to nearest tenth; truncated at
         786,400 for confidentiality; a small number of records have
         wgt_factor < 1)
